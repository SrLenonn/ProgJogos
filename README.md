# Suspicious Kitchen

## Sobre o Jogo
Suspicious Kitchen é um jogo de investigação e culinária, enquanto tenta manter sua simples loja ao longo do dia a dia, você terá que descobrir se seus clientes são humanos de verdade ou outras criaturas disfarçadas. Correndo contra o tempo você terá que descobrir o que são exatamente seus clientes e prepara sua comida, isso sem cometer qualquer deslize durante o rápido processo de atendimento.

## Padrão do Projeto

A organização do projeto segue o seguinte padrão:

- docs/ : Documentos referentes ao game design e direção artística do jogo
- sgdd/ : Documento principal do jogo (Short Game Design Document)
- entidades/ : Documento que lista as entidades, suas funções dentro do jogo, e as relações entre si
- componentes/ : Documento focado em apresentar as componentes das entidades e suas relações dentro do jogo
- src/ : Área destinada ao código fonte do jogo
- assets/ : Área destinada ao deposito dos elementos gráficos do jogo (itens, cenários, personagens, etc...)
